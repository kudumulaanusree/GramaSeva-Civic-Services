Build a complete, production-quality full-stack web application called "GramaSeva" based on this problem statement:

"Create a simple multilingual platform providing rural citizens with information about government services and programs."

IMPORTANT:
This is a Build to Ship hackathon project. Do not create only a static landing page or a mockup. Build a functional, responsive, polished full-stack application with working navigation, search, filters, multilingual support, scheme details, eligibility checking, and an AI-style assistant interface.

==================================================
1. PROJECT GOAL
==================================================

GramaSeva is a citizen-friendly multilingual platform designed for rural citizens.

The platform should make government schemes and services easier to:

- Discover
- Understand
- Search
- Compare
- Check eligibility
- Learn required documents
- Understand application steps
- Access official links
- Ask questions in natural language
- Use in regional languages

The target users are:
- Farmers
- Students
- Women
- Senior citizens
- Rural workers
- Job seekers
- Low digital-literacy users
- General rural citizens

The application must be extremely simple to use.
